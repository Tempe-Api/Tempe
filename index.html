02 / 第一次使用

从注册到看见调用记录

1

注册，准备调用额度

完成邮箱验证，可联系客服领取体验额度，也可在钱包充值。

2

选模型，创建 Key

先看模型广场的价格、分组和客户端限制，再到 API 密钥创建对应分组的测试 Key。首次使用建议设置额度与有效期。

3

填入客户端，发送短请求

选择上方对应教程，填入地址、Key 和完整模型名。先让模型回复一句简短的话，暂时关闭自动循环与批量任务。

4

在日志里看结果

打开使用日志，按调用时间核对模型、Token、响应状态和实际扣费。再用一个小任务评估是否适合继续使用。
